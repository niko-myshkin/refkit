# Contributing

Thanks for trying Refkit. It is an early beta by one person, so feedback matters more than code right now.

## Feedback and bugs
- Impressions, ideas, "this confused me": [Discussions](https://github.com/niko-myshkin/refkit/discussions).
- Something broken: [open an issue](https://github.com/niko-myshkin/refkit/issues/new/choose) and include your macOS and Node versions and whether you used Claude Code or Codex.
- Security problems: report privately, see [SECURITY.md](SECURITY.md).

## Run it locally
```bash
cd app
npm install
npm run dev
```
Open http://localhost:5173. Type-check with `npx tsc -b` before sending a change.

## Pull requests
Small, focused changes are easiest to review. For anything bigger, open a discussion first so we can agree on the direction. By contributing you agree that your work is released under the MIT license of this repository.
