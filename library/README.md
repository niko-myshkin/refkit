# Demo library

A small ready-made library so the app is not empty on first launch: about 50 cards, a few canvases with saved results, a graph.

| What | Source | License |
|---|---|---|
| Interface examples (step indicator, task list, tables, tokens) | U.S. Web Design System (USWDS), GOV.UK Design System, shadcn/ui | public domain, OGL v3.0, MIT |
| Typography and Color scheme notes | Wikipedia | CC BY-SA 4.0 |
| Product frames, app screenshots, canvases and their results | made with Refkit | MIT, like the code |
| Moodboard (Linear, Claude, Arc, Raycast, mymind, teenage engineering, Are.na, Higgsfield, Figma Weave) | screenshots of public web pages, source link in every card | **owned by their authors, not MIT.** Kept here only as references for the demo; will be removed on request |

Every card keeps its source and license in `meta.json`.

Your own materials do not belong here: start the app with `REFKIT_LIBRARY=~/RefkitLibrary npm run dev` to keep them in a separate folder.
